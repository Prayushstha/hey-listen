# Hey Listen!

> A React Native app made to learn the basics of react native and mobile apps development.

Hey Listen! is a mobile app for android and ios from which you will be able to listen to songs offline on your phone with ease with no pain of subscription nor ads.

### The Idea:
Firstly, the name of the project 'hey listen!' came from a popular audio clip from Zelda.
Here is the link to the audio:
>  [Where the name for the project came from](https://youtu.be/P55sOvmHOvs)
