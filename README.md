# Hey Listen!

Hey Listen! is a mobile app for android and ios from which you will be able to listen to songs offline on your phone with ease with no pain of subscription nor ads.

## The Idea:

The name of the project 'hey listen!' came from a popular audio clip from 'The Legend of Zelda: Ocarina of Time', the voiceline from Navi.
Here is the link to the audio:
[Link to the audio clip on youtube.](https://youtu.be/P55sOvmHOvs)

The main motive of this project is for me to learn react native and mobile apps development. Not only that but I have been searching for the perfect music listener app but I face the issues with subscriptions and ads which is annoying. So, I thought it would be interesting for me to learn while solving this problem.

`This is an open-source project made for educational purpose. You are free to use the code, improve/contribute to this repo.`
